Stanford Water Polo · Remote Cheat Sheet

iPhone Controller · Quick Reference
Display: stanford-swim-clock.onrender.com/waterpolo.html  ·  Remote: …?control  ·  TV: …?tv

Game Clock & Shot Clock

Main remote — single-court mode
▶ START / ⏸ STOPBig button. Start/pause the game + shot clock together.
↺ 30Reset shot clock to exactly 30s. Doesn't pause the game.
↺ 20Reset shot clock to exactly 20s.
↺ 15Reset shot clock to exactly 15s.
↺ RESETReset shot to your sticky default (set via SET SHOT). Keeps running.
SET SHOT CLOCKIn Settings → Other. Opens minute/second editor. The value you set becomes the new sticky default.
SET GAME CLOCKIn Settings → Other. Custom minutes/seconds for the game clock.

Scoring

Goals row
+ W / − WAdd or subtract a White goal.
+ B / − BAdd or subtract a Black goal.

Quarter & Horn

▶ NEXT QTRStops the clock, advances to next quarter, resets game + shot, plays horn.
📯 HORNManually fire the air-horn on the scoreboard speakers.

Rest Timer (between quarters)

1:00 / 2:00 / 3:00 / 5:00Full-screen rest countdown on the display, with score still visible.
✕ CANCEL RESTDismiss the rest overlay early.

Transition Timer (drill hustle)

Coach-summoned countdown with beep cadence
⏱ 0:10 / 0:20 / 0:30 / 1:00Full-screen "GET INTO POSITION" overlay on display + TVs. Beep every second in last 10s, big beep at 0.
✕ CANCEL TRANSITIONDismiss the overlay early.

Rep Counter

Enable in Settings → 🔢 REP COUNTER
+1 / −1 / ↺ RESETPer-side rep counters. Badge appears on display top-right (and bottom-right when in split mode).

Shot Clock Modes (drills)

Settings — combinable
🔁 LOOP SHOT CLOCKWhen shot clock hits 0, auto-reset to sticky default + horn + keep running.
🔄 ALTERNATING RESTPairs with LOOP. Cycles work → rest → work (e.g. 12s → 5s ROTATE → 12s). Set Rest Length in Settings.
🎲 RANDOM SHOT CLOCKPairs with LOOP. Each cycle picks a fresh value in your min–max range (default 10–30s).
SHOT-ONLYIn Settings → Other. Hides game clock + quarter dots. Just the shot clock.

Random Exclusion Mode

Settings → 🎯 RANDOM EXCLUSION MODE + paste rosters
Tap a player nameAdds an exclusion to that player — count goes up by 1, 20s out-timer fires.
🎲 EXCL RANDOM WPick a random non-fouled-out white player.
🎲 EXCL RANDOM BPick a random non-fouled-out black player.
↺ RESET ALL EXCLIn Settings. Everyone back to 0 exclusions, clears any active.
Roster formatOne name per line. Add a number to set per-player max: "Marcus 1".

Practice Clock Mode

Settings → 🏊 SHOW PRACTICE CLOCK
⏱ SET TIME / tap timeOpen the minute/second editor for the practice countdown.
▶ START / ⏸ PAUSERun the practice countdown. Horn fires at 0; timer waits.
⏮ PREV / ↺ FIRST / ⏭ NEXTOnly visible when a schedule is pasted in Settings (markdown table). Walks through drills.

Split-Screen Mode

Settings → ⊟ TWO COURTS
Per-side controlsEach side gets its own START, ↺ RESET, ↺ 30/20, ± W/B, SET GAME/SHOT.
?solo=A / ?solo=BURL param to put one side full-screen on the big board.
?tv&side=BTV variant — mirrors Side B instead of Side A.

TV URL Variants

?tvDedicated shot-clock display. Auto-fullscreens on first tap.
?tv&amberAmber digits A/B test for sunlit decks.
?tv&drillsBig game-clock + scores, no shot clock — for drills.

Settings — Defaults & Reset

Quarter LengthMinutes per quarter (default 8). Hit APPLY.
Shot ClockSeconds per shot clock (default 30). Becomes sticky default for ↺ RESET.
⇄ POSSPossession swap — resets shot clock to sticky default. (Doesn't change scores.)
↺ RESET ALLConfirm-gated. Resets quarter, game clock, shot, scores. Doesn't touch roster.

If Something Looks Weird

FlickerA second display tab is open somewhere. Close it (or one display "deposes" itself with a banner).
Phone disconnectsPull-down refresh on Safari. Reconnect is automatic but can be slow.
TV shot clocks differMake sure both TV URLs end in ?tv (not just /waterpolo.html).
One-line tips: All ↺ buttons keep the clock running. ⇄ POSS is the polite reset between possessions. Loop + Alternating + Random can all be on at once (alternating-only-on-work-phase). Practice clock + game clock can't be on at the same time — toggle via the SHOW PRACTICE CLOCK / SHOT-ONLY buttons.
